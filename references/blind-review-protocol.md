# 独立只读子智能体盲审协议（Blind Review Protocol）

创作者本人看自己的渲染草稿天然存在“脑补滤镜”。本协议强制在出 60fps 母带前，由**隔离上下文的独立审片子智能体**执行冷眼验收。

---

## 1. 隔离原则（Strict Isolation）

1. 先运行 `render.mjs --fps 30 --scale 0.5` 生成草稿（~45 秒）。
2. 先执行 CLI `audit-qa` 确认量化指标全部绿灯；若 `bright_pct > 3.5%` 或存在死画面/闪帧，**先修量化再进盲审**。
3. 执行上游 `review_pack.py out/draft.mp4 --film film/ --out out/review_r<N>` 生成审片包。
4. 派生 `research`（只读）子智能体担任 **Independent Film Reviewer**：
   - **仅允许读取** `out/review_r<N>/`（包含 `review.md`、`1_对照联系表.png`、`2_关键帧.png`、`keyframes/`、`motion/`、`transitions/`、`lines.json`、`film.md`）。
   - **严禁读取** `film/index.html`、`film/core.js`、`film/scenes.js` 或任何作者修改记录，防止用代码意图替画面效果辩护。

---

## 2. 9 维评分标准（1–10 分制）

| 维度 | 满分特征（9–10 分） | 常见扣分项 |
| :--- | :--- | :--- |
| **1. 故事清晰度** | 去掉所有口播声只看无声图，仅凭字幕 + 画面动作就能读懂全部科学因果 | 概念跳跃、画面与本句字幕脱节 |
| **2. 开头前 5 秒** | 0.3s 出钩子，特写冲击 + 反直觉数字强悬念，不靠纯黑/空等待 | 前 5 秒文字未出完、钩子平淡或有角落杂字 |
| **3. 画面丰富度** | 暗底 + 主角高光体积材质 + 流动信号 + 环境星尘层次分明 | 主角单薄成扁平线条、重复矩形 UI 卡 |
| **4. 设计秩序** | 五区严格分离，主辅色分工明确，每帧信息预算 `1 主角 + 1 大字 + 0–2 小标注` | 右上角多余读数、多个等大元素平行散落 |
| **5. 变化频率** | 一句一变，句内每 0.8–1.2s 有微动效/脉冲响应，无超 2s 静态画面 | 联系表连续 3 格高度相似 |
| **6. 运动质感** | 看 `motion/*.png`：缓入缓出、节奏卡在 BGM 重拍上，推进具物理重量感 | 匀速机械位移、生硬急停 |
| **7. 转场干净度** | 看 `transitions/*.png`：硬切踩 Drop、光扫/推近无缝、标题延后 0.36s 清晰入场 | `center` 14px 高斯糊影、新旧两层叠化残影 |
| **8. 完成度** | 字幕单行无遮挡无标点、数字计数平滑无重影、结尾与开头意象闭环 | 字幕缩小警报、字母重叠、结尾突兀黑屏 |
| **9. 目标风格贴合度** | 一眼识别为高质感“深空暗底 + 发光生物/微纳线描科技电影” | 灰雾过重泛白、科学写实度失真 |

---

## 3. P0 / P1 硬打回红线与放行门禁

以下任意一条出现即定级为 **P0** 或 **P1**，审片子智能体必须判 **`REJECT`**：

- **P0（严重硬伤）**：
  - 任何文字压字重叠（片名卡与副标题/图腾相撞、Callout 穿过主角核心图形、字幕遮挡底部关键画面、字幕截断出屏）。
  - 科学结构/因果逻辑出现明显硬伤（如物理方向画反、实验结论文字与数值不符）。
  - 出现白/黑单帧闪烁或大于 `2.5s` 的死画面。
- **P1（体验与秩序缺陷）**：
  - 任意过渡条带出现 `14px` 高斯糊影或双画面脏叠。
  - HUD 右上角或背景巨字水印干扰主体注意力。
  - 30fps 草稿 `bright_pct > 3.5%` 或 `p99 < 130` 导致过曝/发灰。
  - 4K 横版封面关键内容超出中心 `4:3` 安全区（`x ∉ [240, 1680]`）。

**最终放行准入条件（必须全部满足，缺一不可）：**
1. **P0 = 0 条，P1 = 0 条**；
2. **9 维均分 `>= 8.5 / 10`**（追求 `>= 9.0 / 10` 标杆）；
3. 每轮修复后必须重新生成 `draft_r<N>.mp4` 与 `out/review_r<N>/`，再次交由盲审确认全绿，严禁“口头假设已修复”直接偷出 60fps 母带。
